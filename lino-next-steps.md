2. Histon Barbers

## Technical recommendation

Use Astro + GitHub + Vercel.

Why:

- fast
- cheap
- mobile-friendly
- simple static sites
- Booksy handles booking
- one repo can control all three sites

## Build rule

Do not build a custom booking system. Use Booksy as the booking engine.

The website’s job is to:

- make each shop look credible
- help customers choose the right location
- push people to the correct Booksy booking page
- improve local search visibility
